## 🛠️ CÔNG CỤ, TIỆN ÍCH & TÍNH NĂNG KHÁC
Tổng hợp các công cụ hỗ trợ tích hợp sẵn trong Comic Downloader GMTPC:

## 1. Tool Tìm Kiếm (Search)
• Nằm ở tab Search cạnh tab Password trong section Nguồn (Source).
• Cho phép gõ tên truyện + chọn domain (TruyenQQ, Nettruyen, Hako...).
• Bấm Search để mở Google khóa chính xác theo domain giúp tìm đúng link gốc cực nhanh.

## 2. Xem Truyện Offline (Watch)
• Đọc ảnh truyện trực tiếp trong app với phím mũi tên Left/Right hoặc A/D.
• Tự động chuyển chapter kế tiếp / trước đó mượt mà.
• Hỗ trợ công cụ Split / Merge chapter trực tiếp trên thư mục local.

## 3. XnConvert & Copy GIF Tools
• Tích hợp công cụ convert ảnh hàng loạt qua XnConvertPortable.
• Quét và copy các file GIF nhanh chóng từ thư mục truyện.

## 4. Tùy Chọn Hoàn Thành & Tắt Máy (Finish Options)
• Cấu hình hẹn giờ tự động tắt máy (Shutdown Timer) sau khi tải xong toàn bộ queue.
• Tự động chạy lệnh custom (Custom Command / Script) khi hoàn thành.

## 🛠️ TOOLS & UTILITIES GUIDE
All-in-one built-in tools in Comic Downloader GMTPC:

## 1. Search Tool
• Located in Search tab next to Password in Source section.
• Enter book name + select target domain checkboxes.
• Click Search to perform Google `site:<domain>` query for direct original links.

## 2. Offline Reader (Watch)
• Read comic images inside app with Left/Right or A/D keys.
• Auto bridges seamlessly to next/previous chapter.
• Integrated Split / Merge chapter tools on local folders.

## 3. XnConvert & GIF Tools
• Batch image conversion via XnConvertPortable integration.
• Quick GIF file scanning & copying tool.

## 4. Finish Options & Auto Shutdown
• Configure auto shutdown timer after download queue completes.
• Run custom command / script upon task completion.
