## 🎈 HƯỚNG DẪN SỬ DỤNG FLOATING BUTTON (NÚT NỔI)
Floating Button là công cụ điều khiển nhanh luôn nằm trên màn hình giúp thao tác cực tiện lợi:

## 1. Phím Tắt Khởi Động & Ghim
• Phím tắt `Ctrl + Shift + F`: Bật hoặc ẩn Nút Nổi bất kỳ lúc nào.
• PIN (Ghim): Giữ Nút Nổi luôn hiển thị trên cùng (TopMost) đè lên các cửa sổ trình duyệt khác.
• MOVE: Nhấp giữ nút MOVE để kéo Nút Nổi đến vị trí bất kỳ trên màn hình.

## 2. Các Tính Năng Điều Khiển Nhanh
• AUTO PASTE: Bật tự động bắt link khi Ctrl+C từ trình duyệt (Nhớ tắt khi dừng get link).
• DOWNLOAD / RETRY: Bật/Tắt nhanh tiến trình tải hoặc thử lại mà không cần chuyển về cửa sổ app.
• OPEN FOLDER (`Ctrl+Shift+O`): Mở ngay thư mục chứa truyện đã tải.
• CLEAN TEMP: Dọn dẹp cache ảnh preview và dữ liệu tạm `.tmp` giúp giải phóng ổ cứng.
• GLOBAL KEY (`Alt+Shift+G`): Bật hotkey toàn hệ thống kể cả khi đang dùng app khác.

## 🎈 FLOATING BUTTON GUIDE
Floating Button provides fast desktop controls for quick actions:

## 1. Launch Shortcut & Pin
• Shortcut `Ctrl + Shift + F`: Show or hide Floating Button anytime.
• PIN: Keep Floating Button Always On Top of all browser windows.
• MOVE: Drag and position Floating Button anywhere on screen.

## 2. Quick Control Actions
• AUTO PASTE: Auto capture copied URLs from browser (Remember to turn OFF when done).
• DOWNLOAD / RETRY: Quickly toggle download/retry without focusing main window.
• OPEN FOLDER (`Ctrl+Shift+O`): Instantly open downloaded root folder.
• CLEAN TEMP: Clean `.tmp` and preview image cache to free up disk space.
• GLOBAL KEY (`Alt+Shift+G`): Enable global hotkeys while working in other apps.
